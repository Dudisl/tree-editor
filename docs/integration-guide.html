Tree Editor — מדריך אינטגרציה

איך להשתמש ברכיב הגנרי בתוך אפליקציית Next.js. מתייחס לענף tree-components-customActions.

1. התקנה

npm install github:Dudisl/tree-editor#tree-components-customActions

לאחר מיזוג לענף היציב, עדכן את ההפניה ל־commit/tag יציב. הגדר ב־next.config.js:

module.exports = { transpilePackages: ["tree-editor"] };

2. איפה נמצא ה־JSON?

ה־Host קובע היכן קובצי JSON מאוחסנים באמצעות ProjectAdapter. ה־TE מבקש את הפרויקט דרך API ואינו קורא דיסק מהדפדפן.

import path from "node:path";
import { promises as fs } from "node:fs";
import type { ProjectAdapter } from "tree-editor/server";

const dir = path.join(process.cwd(), "storage", "models");

export const adapter: ProjectAdapter = {
  async listProjects() {
    await fs.mkdir(dir, { recursive: true });
    return (await fs.readdir(dir))
      .filter(name => name.endsWith(".json"))
      .map(name => name.slice(0, -5));
  },
  projectFilePath(project) {
    if (!/^[a-zA-Z0-9_-]+$/.test(project)) throw new Error("Invalid project");
    return path.join(dir, project + ".json");
  },
  async ensureDataDir() { await fs.mkdir(dir, { recursive: true }); }
};

אם ל־Host כבר יש Adapter, השתמש בו במקום ליצור חדש.

3. חיבור API לטעינה ושמירה

בקובץ app/api/treeEditor/tree/route.ts של ה־Host:

import { createTreeEditorRoutes } from "tree-editor/server";
import { adapter } from "../../../../lib/treeEditorAdapter";
export const { GET, POST } = createTreeEditorRoutes(adapter);

ה־TE קורא GET לטעינת פרויקט ו־POST לשמירתו. בסביבת Production חובה לבצע בדיקות הרשאה ב־Host.

4. הצגת העורך

"use client";
import { TreeEditorApp } from "tree-editor/client";
export default function Page() {
  return <TreeEditorApp />;
}

כך מקבלים תצוגת עץ, עריכה ושמירה דרך ה־API שחיברנו.

5. התאמת תצוגת JSON

const uiConfig = {

אפשר להגדיר גם inlineKeys, typeColors, palette, longTextThreshold ועוד.

6. קריאת בחירת המשתמש

<TreeEditorApp onContextChange={(ctx) => {
  console.log(ctx.project, ctx.document);
  console.log(ctx.selectedPath, ctx.selectedNodeId);
}} />

selectedPath הוא נתיב מבני בתוך ה־JSON, למשל ["children",0,"children",2]. כל מחרוזת היא מפתח באובייקט וכל מספר הוא אינדקס במערך.

7. הפעלת פעולות חיצוניות

import { TreeEditorApp } from "tree-editor/client";
import type { HandlerRequest, HandlerResult } from "tree-editor/client";

const actions = [
  { caption: "פירוק צומת", handlerName: "decompose" },
  { caption: "יצירת תוכן", handlerName: "create" }
];

async function onAction(request: HandlerRequest): Promise<HandlerResult> {
  const res = await fetch("/api/tree-actions", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(request)
  });
  if (!res.ok) return { success: false, error: "HTTP " + res.status };
  return res.json();
}

<TreeEditorApp actions={actions} onAction={onAction} />

onAction מקבל handlerName, project, nodePath. ה־Host מממש /api/tree-actions, מחליט איזה Handler להפעיל ושומר את תוצאתו. רק לאחר הצלחת ה־Handler ה־TE טוען את הפרויקט מחדש. לפני הפעלת ה־Handler ה־TE מאשר את שמירת המסמך.

8. רכיבים נפרדים — עבור עמוד מותאם

import {
  TreeEditorProvider, TreeEditorHeader,
  TreeEditorTree, TreeEditorNodeForm
} from "tree-editor/client";

<TreeEditorProvider uiConfig={uiConfig} actions={actions} onAction={onAction}>
  <TreeEditorHeader />
  <div className="my-layout">
    <TreeEditorTree showToolbar />
    <TreeEditorNodeForm />
  </div>
</TreeEditorProvider>

OrgRefactor כבר משתמש במסלול הזה, ולכן אין צורך להחליף את המבנה הקיים. הוסף רק props חסרים.

9. בדיקת שימוש

  1. הרץ את ה־Host המקומי באמצעות npx next dev -p 3005 -H 127.0.0.1.
  2. בחר פרויקט וודא שה־JSON נטען.
  3. ערוך שדה, שמור וודא שהקובץ השתנה.
  4. בחר צומת, הפעל Action וודא שה־JSON המעודכן מופיע לאחר Reload.
enableBackup ו־enableWireframe הן יכולות אופציונליות הדורשות מסלולי שרת נוספים ב־Host. ה־TE אינו מפעיל Python בעצמו; זה תפקיד ה־Host.
